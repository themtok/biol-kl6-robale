# Robale pod lupą — biologia, klasa 6

Responsywna strona do powtórki z trzech grup zwierząt: **płazińce, nicienie, pierścienice**. Bez działu o parzydełkowcach.

## Zawartość
- Trzy lekcje i tabela porównawcza.
- Żywiciele, pasożyty, cykle rozwojowe i zapobieganie zakażeniom.
- 28 interaktywnych fiszek.
- Test z 24 pytaniami, oceną oraz wyjaśnieniami błędów.

Treści opracowano na podstawie zdjęć stron 33–48 podręcznika dostarczonych w rozmowie. Strona nie zbiera danych, nie wysyła odpowiedzi na serwer. Nie wymaga logowania.

## GitHub Pages
1. Otwórz **Settings → Pages** w tym repozytorium.
2. W **Build and deployment → Source** wybierz **GitHub Actions**.
3. Otwórz kartę **Actions**, workflow **Deploy GitHub Pages** i uruchom **Run workflow**, jeśli wdrożenie nie wystartowało automatycznie.
4. Strona będzie dostępna pod adresem: https://themtok.github.io/biol-kl6-robale/

## Uruchomienie lokalne
Otwórz `index.html` w przeglądarce. Żaden build ani serwer nie jest wymagany.

## Pliki
- `index.html` — zawartość lekcji.
- `style.css` — wygląd i układ mobilny.
- `app.js` — fiszki i sprawdzian.
- `.github/workflows/pages.yml` — publikacja GitHub Pages.

Fonty pochodzą z Google Fonts; w razie braku sieci używane są czcionki systemowe.
